# Noxxus System

## Fichas Diárias

A página `Fichas Diárias` precisa do serviço local para alterar a planilha do computador.

Para iniciar:

```powershell
npm run fichas:service
```

Ou abra o arquivo `Abrir Fichas Diarias Local.bat`.

O sistema procura a planilha `fichas-diarias.xlsx` na pasta padrão:

`Documentos\Noxxus System\Fichas Diarias`

Se a planilha não existir, ela será criada com as abas `FICHADIARIAGERAL` e `VALES`.
